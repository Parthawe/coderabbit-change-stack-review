I've finished the Change Stack assignment using the Formbricks PR. I worked through the design in Paper, then built a prototype to try the interactions.

The original has a lot competing with the code. I kept the layers, brought the file controls together, and made it clearer which code each summary refers to. I also separated marking a file viewed from submitting a review, so progress and the final decision don't get mixed up.

The prototype covers seven file diffs; submitting a review is simulated. Paper may ask you to sign in, but the other links are public.
